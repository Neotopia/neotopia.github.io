# Lisa Momas — Portfolio

Personal portfolio site for Lisa Momas, Digital Analytics & Data Analyst.

**Live site → [neotopia.github.io](https://neotopia.github.io)**

## About

Single-page portfolio built to stand out during job searches in digital analytics and data. Covers background, skills, and projects.

## Stack

- Plain HTML/CSS — single `index.html` file, no build step
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts
- Hosted on GitHub Pages

## Structure

```
index.html        # Main portfolio page
/dashboards/      # Future: standalone HTML dashboards linked from the portfolio
```
